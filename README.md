# website-copy-maker

> Public mirror — content is published from the internal working repo via a
> gated GitHub Actions workflow with security scans.

This repository is a read-only mirror of
[`website-copy-maker-internal`](https://github.com/intelligent-iterations/website-copy-maker-internal),
the working repo for `site2react-agent` — a TypeScript CLI that reconstructs
any public website as a clean, self-hostable Next.js + Tailwind project.

The first published release will land here once the internal package is
ready for OSS exposure. Until then, this repo holds only this notice.
